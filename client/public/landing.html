Platform Capabilities

Everything You Need,
Nothing You Don't

Seven core capabilities that make Synergasia the only tool your counseling practice needs.

🔐

Enterprise RBAC

Four permission levels enforced at every API endpoint and UI component. Developer → Admin → Counselor → Student.

⚙️

Dynamic Profiles

Admins define custom fields, categories, and visibility rules. Text, number, date, and dropdown types supported.

✅

Task Management

Create and assign tasks with due dates. Auto-populates student planners. Status tracked: Pending → In Progress → Done.

📁

Activity Portfolio

Students log extracurriculars and outcomes. Counselors provide written feedback. Builds a rich application portfolio over time.

🎓

University Planning

Curated catalogue with rich data. Students categorise schools as Reach, Target, or Safety with counselor guidance.

📄

Secure Documents

Counselors upload PDFs, Word docs, and images to student profiles. Per-document visibility toggle. Role-enforced storage.

🔔

Push Notifications

Real-time in-app alerts and device push notifications for tasks, messages, feedback, and upcoming planner events.

The Workflow

From Setup to Student Success

2

Students are assigned to counselors with one click. Role scoping is automatic — no extra config needed.

3
